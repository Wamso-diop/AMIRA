Lire. Comprendre. Agir.

Amira rend les services financiers numériques compréhensibles en fulfulde, directement dans votre navigateur, sans rien changer au site.

Ce guide vous montre comment l’installer dans Chrome en quelques minutes.

2 / 9

L’extension est déjà construite

npm run dev a créé le dossier front/dist et le met à jour à chaque modification du code. C’est ce dossier que Chrome va charger.

Dans le dossier du projet : AMIRA › front › dist

8 / 9

Activez « Traduire cette page »

Amira détecte la langue du site : français ou anglais vers le fulfulde, fulfulde vers le français ou l’anglais. La première fois sur un nouveau site, Chrome demande votre accord une seule fois.

Après une modification du code, cliquez sur ↻ sous Amira dans chrome://extensions.
